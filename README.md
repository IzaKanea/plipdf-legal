# plipdf-legal

Les pages publiques de l'application **Plipdf** (Kanea consulting SRL).

- `index.html` — politique de confidentialité
- `support.html` — page d'assistance (URL demandée par App Store Connect)

Publiées via GitHub Pages.

Ce dépôt ne contient **que** le site public. Le code de l'application vit
ailleurs, dans un dépôt local séparé (`~/Desktop/PDF/plipdf-app`), et n'est
jamais publié.

## Mettre une page à jour

1. Modifier `index.html` ou `support.html` (penser à la date de « Dernière mise à jour »).
2. `git add -A && git commit -m "…" && git push`
3. GitHub Pages republie tout seul, en une minute environ.
